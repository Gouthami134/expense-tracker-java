# Expense Tracker (Java)

An original command-line learning project for recording dated expenses, listing entries, and calculating the total. Entries stay in memory and are cleared when the program exits.

## Requirements
- Java Development Kit (JDK) 17 or later
- A terminal

## Run
```sh
javac ExpenseTracker.java
java ExpenseTracker
```

## Concepts
Java records, LocalDate, lists, streams, menu loops, formatted output, and input validation.

## Scope
This starter project does not persist data and is not a financial service.
